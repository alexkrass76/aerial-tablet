Aerial Tablet 1.3.0
Дата сборки: 5 ноября 2026

Нативный домашний экран для Android 10+, проверен на U8 / Android 13
с экраном 1200×1920, плотностью 210 dpi, в обеих ориентациях.
Пакет: app.aerial.tablet. Реализация: Java + Android framework.
Внешних runtime-библиотек и серверной части нет.

Возможности
• Крупные часы и дата, системный формат времени и часовой пояс.
• Закреплённый внизу док в стиле iPadOS: до шести приложений без подписей,
  матовое стекло Aerial с размытыми обоями, мягкими углами и светлой кромкой.
  Удержание открывает добавление,
  удаление из дока, перемещение левее и информацию о приложении.
• Основное меню приложений открывается кнопкой справа в доке или свайпом
  вверх. В нём — каталог реальных приложений и поиск по названию и пакету.
• Автоматическое обновление списка при установке/удалении приложений.
• Пункт управления: Wi-Fi, Bluetooth, громкость мультимедиа,
  яркость домашнего экрана и переход в системные настройки.
• Единое матовое стекло для дока, меню приложений, пункта управления,
  оформления, контекстных меню, поля поиска и подложек кнопок.
• Четыре фона Aerial: рассвет, ночь, туман и сумерки.
• Детский режим: одобренные приложения, отдельный док и поиск, выход по PIN.
• Сохранение избранного, оформления и детского режима между перезапусками.
• Портретная и альбомная компоновка, кнопка Home возвращает к часам и доку.

Управление
Коснитесь значка для запуска; удерживайте для меню.
Кнопка с сеткой справа в доке открывает основное меню приложений с поиском.
Свайп вверх по домашнему экрану открывает то же меню.
В самом меню приложения прокручиваются, поле поиска фильтрует список.
Плашка сети и заряда справа сверху открывает пункт управления.
Пункт «Оформление» находится в пункте управления.
Нажатие на часы открывает будильники.
Ползунок яркости меняет яркость только окна оболочки; для всех приложений
используйте «Настройки экрана». Громкость меняется для мультимедиа системы.

Детский режим
Откройте плашку сети и заряда → «Детский режим» в пункте управления.
1. Откройте «Разрешённые приложения», отметьте приложения и сохраните список.
   Первоначально предложены установленные YouTube Kids и Bimi Boo; список
   применяется только после нажатия «Сохранить список».
2. Задайте и повторите свой PIN из 4–8 цифр.
3. Нажмите «Включить детский режим».

В детском режиме док и библиотека показывают только разрешённые приложения.
Настройки, информация о приложениях, редактирование избранного и переход
в будильник скрыты. Обычный док сохраняется отдельно.
Кнопка «Родителям» справа сверху открывает ввод PIN. Правильный PIN возвращает
обычный домашний экран. Для изменения списка, смены или удаления PIN нужно
снова ввести действующий код в настройках детского режима.
После пяти ошибок ввод временно приостанавливается; повторные ошибки
увеличивают паузу до пяти минут. Пауза сохраняется при перезапуске приложения.
PIN не хранится открытым: PBKDF2-HMAC-SHA256, 600000 итераций, случайная соль
16 байт, сравнение хешей без раннего выхода. Вычисление выполняется вне UI.
Экраны установки и ввода PIN защищены от снимков экрана.
Заводского/мастер-кода нет. Реальный код задаётся на планшете владельцем.
Встроенного восстановления забытого PIN нет.

Граница режима: это ограничение домашнего экрана. Системная шторка,
недавние приложения, другие пользователи Android и переходы из приложений
не блокируются. Для строгого киоска требуется отдельная настройка Android DPC
и lock task mode: https://developer.android.com/work/dpc/dedicated-devices/lock-task-mode
Назначение Device Owner, очистка планшета и системные ограничения не выполнялись.
После проверок временные тестовые коды и список удалены. Детский режим выключен.

Сборка
Нужны JDK 17, Android SDK platform android-36 и build-tools 36.0.0.
На macOS/Linux:
  JAVA_HOME=/path/to/jdk17 ANDROID_HOME=/path/to/sdk ./build.sh
При другой установленной версии SDK можно задать SDK_PLATFORM и BUILD_TOOLS.
Результат: build/aerial-tablet.apk. Gradle и скачивание зависимостей не нужны.
Ключ подписи для обновлений создаётся в signing/aerial-tablet.jks.
Сохраняйте этот локальный каталог: обновления установленного пакета требуют
того же ключа. В распространяемый архив исходников ключ не включён.

Установка и восстановление
  python3 install.py SERIAL
Порт по умолчанию — 5037. Прежний Home и список accessibility-служб
сохраняются в .local-state/before.json до первого переключения.
При установке выбирается новый Home и снимается только перехват
hk.ithkservice.kidlock/.KidModeProtectionService. Остальные службы сохраняются.
Приложения и их данные не удаляются. Root не требуется.
Возврат из той же рабочей папки:
  python3 install.py SERIAL --restore

Dock RGB = 0.8 × обои + 30; Panel RGB = 0.48 × обои + 14;
сглаживание углов 0.6, блик 10% и кромка 1.2dp с градиентом света.

обоев или ориентации. Иконки и текст остаются резкими.
